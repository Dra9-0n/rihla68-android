رحلة 68 — مشروع تطبيق Android مستقل
====================================

الهوية
- الاسم: رحلة 68
- معرّف التطبيق: com.rihla68.app
- النوع: تطبيق Android أصلي من حيث الحزمة والتثبيت، بواجهة محلية مضمّنة داخل WebView.
- اللغة: العربية، مع دعم RTL.
- لا يحتاج إلى استضافة موقع أو متصفح لتشغيله.

الوظائف الموجودة في الواجهة
- ملف شخصي وأهداف قابلة للتخصيص، دون وزن أو هدف مفروض.
- جدول أسبوعي متكرر للتعليم، مع إضافة التزامات متغيرة مثل مكافحة الآفات.
- اليوميات والعادات والنوم.
- تسجيل حصص التدريب وسجل الوزن.
- ملاحظات التغذية.
- تقارير قابلة للطباعة.
- تصدير واستعادة نسخة احتياطية JSON من خلال منتقي ملفات Android.
- تخزين محلي على الجهاز.

البناء
- Android Gradle Plugin 8.6.1
- Gradle 8.7
- Java 17
- compileSdk 35 / minSdk 23
- سير عمل GitHub Actions موجود في .github/workflows/build-apk.yml لبناء app-debug.apk.

مهم قبل التوزيع
هذا الأرشيف هو مصدر المشروع، وليس ملف APK جاهزاً. لا يمكن وصفه بأنه إصدار نهائي قبل تنفيذ بناء Android فعلي واختباره على جهاز Android حقيقي. بيئة إعداد هذا المشروع لا تحتوي حالياً على Android SDK أو Gradle، ولا تملك صلاحية الوصول إلى حساب GitHub الخاص بالمستخدم لتشغيل البناء السحابي نيابة عنه.

ملاحظات تقنية
- البيانات تحفظ محلياً في WebView localStorage.
- النسخ الاحتياطي والاستعادة يستخدمان واجهة Android الأصلية لفتح/حفظ ملف JSON.
- لا توجد حالياً حسابات مستخدمين أو مزامنة سحابية أو إشعارات.
- البناء الحالي Debug للتجربة؛ إصدار Google Play يتطلب توقيع Release وسياسة خصوصية واختبارات إضافية.
